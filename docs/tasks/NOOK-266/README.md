# NOOK-266 저신뢰 카카오 장소 검색 시 네이버 후보 병합

## 목적

카카오 검색 결과의 신뢰도가 낮아 네이버 검색까지 수행했음에도 네이버 후보가 최종 후보 목록에서
제외되어 정확한 장소를 선택하지 못하는 문제를 수정한다.

## 재현 사례

- dev post 371 (`external_post_id=DcDsLZjGn_N`)
- 장소 단서: `어니언 안국`, `서울 종로구 계동길 5`
- 카카오 검색: `어니언컴퍼니 안국점` 등 6건, 최고 점수 55
- 네이버 검색: 정확한 상호명 `어니언 안국` 1건
- 네이버 후보가 카카오 검증 점수에만 사용되어 `strictMatchCount=0`으로 누락

## 범위

- 카카오 최고 점수가 신뢰 기준 미만이면 카카오와 네이버 후보를 병합한다.
- 병합 후 provider와 외부 장소 ID가 같은 후보를 중복 제거한다.
- 카카오 후보의 네이버 검증 점수와 기존 정렬을 유지한다.
- 카카오 신뢰도가 충분한 경우 네이버 검색을 생략하는 기존 동작을 유지한다.
- 재현 및 중복 방지 회귀 테스트를 추가한다.

## 제외 범위

- 장소명 정규화 규칙 변경
- 외부 provider API 계약 변경
- 공개 API 및 DB 스키마 변경
- 기존 게시물 일괄 재파싱

## 성공 기준 및 검증

- 저신뢰 카카오 결과가 있어도 네이버의 정확 일치 후보가 최종 후보에 포함된다.
- 병합 결과에 동일 provider와 외부 장소 ID를 가진 후보가 중복되지 않는다.
- 카카오 고신뢰 결과는 기존처럼 네이버 검색 없이 반환된다.
- `./gradlew detekt`, `./gradlew test`, `./gradlew check`가 통과한다.
