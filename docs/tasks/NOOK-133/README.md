# NOOK-133 장소 썸네일 파싱 상태 제공

## 목적

장소 파싱 완료 후 별도 비동기로 처리되는 썸네일 저장 상태를 API 응답에 명시해,
클라이언트가 이미지 대기 여부를 추측하지 않게 한다.

## 범위

- 장소별 썸네일 파싱 상태 저장 컬럼 추가
- 썸네일 처리 시작, 완료, 실패 상태 기록
- 게시물 장소 파싱 응답과 장소 상세 응답에 `thumbnailParsingStatus` 추가
- 저장 게시물 상세의 장소 응답에도 같은 상태 추가

## 제외 범위

- 클라이언트 폴링 정책 변경
- 썸네일 재시도 큐 신설
- 기존 썸네일 URL 재수집

## 검증

- `./gradlew test`
- `./gradlew check`
