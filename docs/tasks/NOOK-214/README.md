# NOOK-214 내 저장 장소 검색에 그룹별 필터 제공

## 목적

내 저장 장소 검색 결과를 그룹별로 구분하고, 사용자가 그룹을 선택하면 해당 그룹에 연결된 장소만
확인할 수 있도록 합니다.

## 범위

- 기존 `GET /api/v1/places/saved/search`에 선택 입력 `groupId`를 추가합니다.
- `groupId`가 없으면 내 전체 저장 장소를 중복 없이 검색합니다.
- `groupId`가 있으면 해당 그룹의 저장 게시물과 연결된 장소만 검색합니다.
- 응답에 검색 결과가 존재하는 그룹의 `id`, `name`, `color`, `matchedPlaceCount`를 추가합니다.
- 한 장소가 여러 그룹에 연결된 경우 각 그룹의 검색 개수와 필터 결과에 포함합니다.
- 본인 소유의 활성 그룹만 필터로 사용할 수 있도록 검증합니다.
- API 문서, HTTP Client 예시 및 회귀 테스트를 갱신합니다.

## 제외 범위

- 그룹 생성·수정·삭제 기능 변경
- 공유받은 그룹 검색
- 외부 장소 provider 검색
- 초성·유사어·오타 보정 검색
- DB 스키마 변경

## 성공 기준

- 그룹을 지정하지 않으면 내 전체 검색 결과와 그룹별 일치 개수가 반환됩니다.
- 유효한 `groupId`를 지정하면 해당 그룹에 연결된 검색 결과만 반환됩니다.
- 존재하지 않거나 본인 소유가 아닌 그룹은 조회할 수 없습니다.
- 동일 장소가 전체 결과에서 중복 노출되지 않습니다.
- 기존 `query`, `page`, `size` 요청과 장소 응답 필드는 호환성을 유지합니다.
- 관련 테스트와 `./gradlew check`가 성공합니다.
