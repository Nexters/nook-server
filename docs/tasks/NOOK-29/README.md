# NOOK-29 저장 게시물 목록·상세 조회 API

## 목적

사용자가 저장한 게시물 목록과 상세 정보를 사용자 소유 경계를 지키면서 조회할 수 있도록 합니다.

## 범위

- 저장 게시물 목록 조회와 page 기반 pagination
- 저장 시각과 저장 게시물 ID 내림차순 정렬
- 게시물 제목, 작성자와 대표 미디어를 포함한 목록 요약
- 본문, 원문 URL, 발행 시각, 전체 미디어, 해시태그를 포함한 상세 조회
- 사용자 메모와 저장 시각 반환
- 연관 장소와 장소별 북마크 상태 반환
- 장소 파싱 상태 반환
- HTTP Client 요청과 OpenAPI 갱신

## 제외 범위

- 메모 편집
- 게시물 삭제
- 그룹별 필터링
- 지도 viewport 조회
- 데이터베이스 스키마 변경

## API

- `GET /api/v1/posts?page=0&size=20`: 저장 게시물 목록
- `GET /api/v1/posts/{postId}`: 저장 게시물 상세

공개 API의 `postId`는 사용자별 `user_saved_posts.id`입니다. 상세 조회는 현재 사용자 ID와 이 ID를
함께 조회하여 다른 사용자의 게시물을 `404 Not Found`로 처리합니다.

## 성공 기준

- 장소가 없거나 장소 파싱이 진행 중·실패한 게시물도 조회할 수 있습니다.
- 미디어, 해시태그와 장소 순서가 저장된 표시 순서대로 유지됩니다.
- 다른 사용자의 저장 게시물은 존재하지 않는 것과 동일하게 처리합니다.
- 목록은 안정적인 정렬과 pagination 정보를 제공합니다.
- `./gradlew check`가 성공합니다.

## 검증

```shell
./gradlew detekt
./gradlew test
./gradlew check
```
