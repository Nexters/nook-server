# NOOK-271 장소 검색을 네이버 우선·카카오 폴백으로 전환

## 목적

Instagram에 기재된 매장명이 네이버 등록명과 일치하는 경우가 더 많은 운영 경험을 반영해 자동 장소
파싱의 provider 우선순위를 변경한다.

## 범위

- 자동 장소 검색을 네이버 우선으로 수행
- 네이버 결과가 없거나 신뢰도가 낮거나 호출에 실패하면 카카오 검색
- 두 provider 후보를 병합하는 경우 네이버 후보 우선
- provider 우선순위와 fallback 동작 테스트
- 기존 공개 수동 장소 검색 API의 카카오 pagination 동작 유지

## 제외 범위

- provider API 계약 변경
- DB 스키마 변경
- 공개 수동 장소 검색 API provider 변경

## 검증

- 신뢰도 높은 네이버 후보가 있으면 카카오를 호출하지 않고 네이버 후보를 반환한다.
- 네이버 결과가 저신뢰이거나 호출에 실패하면 카카오 후보를 조회한다.
- 두 provider 후보를 병합하면 네이버 후보가 먼저 정렬된다.
- `./gradlew check`
