# NOOK-277 장소 파싱 완료 후 게시물 최종 제목 결정

## 목적

게시물 제목을 첫 이미지 OCR에 고정 우선순위로 의존하지 않고, 본문·OCR·확정된 장소 정보를 종합해
장소 파싱의 마지막 단계에서 결정한다.

## 범위

- 콘텐츠 파싱은 본문과 해시태그, 첫 이미지 OCR, 텍스트 장소 단서만 저장한다.
- 장소 검색과 후보 검증이 끝난 뒤 최종 제목 선택기를 실행한다.
- 선택기는 본문, 해시태그, 위치 태그, 첫 이미지 OCR, 확정 장소명·주소·지역·카테고리를 사용한다.
- 제목 확정과 장소 관계 저장은 장소 파싱 완료 처리 전에 수행한다.
- 제목 provider 실패 또는 장소 개수 충돌 시 확정 장소 기반의 결정론적 fallback을 적용한다.
- 제목 확정 진행률 마일스톤을 추가한다.
- 운영자가 수정한 제목은 자동 파싱으로 덮어쓰지 않는다.

## 제외 범위

- 장소 사진 provider 및 썸네일 파싱 변경
- OCR provider 변경
- 공개 API 및 DB 스키마 변경
- 기존 게시물 일괄 재생성

## 성공 기준

- 파싱 진행률이 100%가 되는 시점에 최종 제목이 저장되어 있다.
- 제목은 본문·OCR·확정 장소 중 확인 가능한 사실만 사용한다.
- 계정명, 로고, PICK·VOL 같은 배지와 본문에 충돌하는 OCR은 제목 근거에서 제외한다.
- 본문에 명시된 장소 개수와 확정 장소 개수가 다르면 제목에서 숫자를 생략한다.
- 제목 선택 provider 실패가 장소 파싱 완료를 막지 않는다.
- 운영자가 수정한 제목과 검수한 장소 매핑을 보호한다.
