# NOOK-132 가입 시 기본 그룹 생성

## 목적

신규 가입 사용자가 공유하기/저장 화면에서 바로 사용할 수 있는 기본 그룹을 제공한다.

## 범위

- 소셜 로그인 신규 가입 플로우에서 멤버 생성 시 기본 그룹 생성
- 기본 그룹 이름은 `내 아카이브`
- 기본 그룹 색상은 클라이언트 기본 표시와 맞는 `BLUE`
- 기존 가입 사용자의 로그인 흐름에는 그룹을 추가 생성하지 않음
- 유스케이스 테스트 보강

## 제외 범위

- 기존 사용자 데이터 백필
- 기본 그룹명/색상 설정 API
- 클라이언트 UI 변경

## 검증

- `./gradlew test`
- `./gradlew detekt`
