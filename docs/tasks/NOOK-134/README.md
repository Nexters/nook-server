# NOOK-134 게시물 처리 진행률 API 제공

## 목적

클라이언트가 기존 게시물 API 폴링 응답만으로 로딩 화면의 진행률을 표시할 수 있도록 게시물 처리 진행률을 제공한다.

## 범위

- `POST /api/v1/posts` 응답에 `processingPercent`를 추가한다.
- `GET /api/v1/posts` 응답의 저장 게시물 요약에 `processingPercent`를 추가한다.
- `GET /api/v1/posts/{postId}` 응답의 저장 게시물 상세에 `processingPercent`를 추가한다.
- 그룹 게시물 목록 응답도 같은 저장 게시물 요약 모델을 사용하므로 `processingPercent`를 포함한다.
- 진행 중 상태에서는 현재 단계의 시작 시각과 예상 소요 시간을 기준으로 진행률을 계산한다.
- 완료 상태에서는 즉시 `100`을 반환한다.

## 제외 범위

- 클라이언트 코드 수정
- 별도 진행률 조회 API 신설
- DB 스키마 변경

## 진행률 기준

- 콘텐츠 파싱 대기: `5`
- 콘텐츠 파싱 진행: `15`에서 `45`까지 45초 동안 증가
- 장소 파싱 대기: `50`
- 장소 파싱 진행: `60`에서 `95`까지 90초 동안 증가
- 전체 완료: `100`

진행 중 상태의 시작 시각은 각 parsing job이 `PROCESSING`으로 갱신된 시각을 기준으로 한다. 예상 시간을 초과해도 완료 전에는 단계별 상한값을 넘지 않는다.

## DDL
