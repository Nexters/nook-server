# NOOK-265 정확한 상호명 후보의 주소 표현 불일치 복구

## 목적

지도 provider가 정확한 상호명의 장소를 반환했음에도 게시물 지번 주소와 provider 도로명 주소가
문자열상 일치하지 않아 후보가 제거되는 문제를 수정한다.

## 재현 사례

- dev post 421 (`source_post.id=356`)
- 장소 단서: `Ordinary Noise Club`, `서울시 마포구 망원동 378-17`
- 네이버 정확 이름 검색 결과 1건 반환
- 주소 호환 후보가 0건이 되어 `No place candidate found`로 실패

## 범위

- 기존 주소 호환 후보를 최우선으로 유지한다.
- 주소 호환 후보가 없을 때 정확한 이름 쿼리로 발견된 정확한 이름의 후보가 하나뿐이고
  행정구역 및 층·호가 충돌하지 않으면 후보 선택 대상으로 복구한다.
- 지역이 다른 동명 장소와 여러 동명 후보는 자동 복구하지 않는다.
- 재현 및 오매칭 방지 회귀 테스트를 추가한다.

## 제외 범위

- 지도 provider 교체
- 공개 API 및 DB 스키마 변경
- 기존 게시물 일괄 재파싱
- 일반 장소 중복 병합 정책 변경

## 성공 기준 및 검증

- 지번·도로명 표현이 달라도 정확한 이름 검색의 안전한 단일 후보가 선택된다.
- 행정구역이 충돌하거나 동명 후보가 여러 개인 경우 자동 선택되지 않는다.
- 기존 층·호 충돌 방지 동작을 유지한다.
- `./gradlew detekt`, `./gradlew test`, `./gradlew check`가 통과한다.
