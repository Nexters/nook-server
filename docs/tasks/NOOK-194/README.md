# NOOK-194 그룹 목록 썸네일을 Instagram 대표 이미지로 수정

## 목적

`GET /api/v1/groups`의 `thumbnailUrls`가 장소 썸네일을 우선 반환하는 문제를 수정하고,
Instagram 게시물의 대표 이미지를 우선 반환합니다.

## 범위

- 그룹별 최근 게시물 최대 3개의 썸네일 선택 기준을 수정합니다.
- 게시물의 첫 Instagram 이미지가 있으면 장소 썸네일보다 우선 사용합니다.
- 게시물 이미지가 없을 때는 기존처럼 첫 장소 썸네일을 사용합니다.
- 최신 저장순, 최대 3개, 실패 게시물 제외 및 사용자 격리 조건을 유지합니다.
- 게시물 이미지와 장소 썸네일이 함께 존재하는 회귀 테스트를 추가합니다.

## 제외 범위

- `thumbnailUrls` 응답 타입 변경
- 동영상 URL 반환 또는 동영상 썸네일 생성
- 그룹 상세 게시물 `representativeMedia` 정책 변경
- DB 스키마 및 기존 저장 데이터 변경

## 성공 기준

- 게시물 이미지와 장소 썸네일이 모두 있으면 게시물 이미지가 반환됩니다.
- 게시물 이미지가 없으면 장소 썸네일이 반환됩니다.
- 최신순, 최대 3개, 실패 게시물 제외 및 사용자 격리 조건이 유지됩니다.
- `./gradlew check`가 통과합니다.
