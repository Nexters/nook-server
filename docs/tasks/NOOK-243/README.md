# NOOK-243 어드민 사용성 원칙 수립과 연결 탐색 개선

## 목적

어드민 기능을 확장할 때 일관된 사용성을 유지하도록 구현 원칙을 문서화하고, 현재 화면의 연결 탐색과 불필요한 인증 정보 노출을 개선한다.

## 범위

- `nook-admin-web/AGENTS.md` 사용성 원칙 작성
- 게시글 상세 장소에서 장소 관리 상세로 이동
- 장소 상세 게시글에서 게시글 관리 상세로 이동
- 대시보드에서 인증 구현과 개인 이메일 노출 제거
- 대시보드를 주요 관리 업무 진입점으로 구성

## 제외 범위

- 인증 방식 변경
- 관리자 API 계약 변경
- 새로운 관리 기능 추가

## 성공 기준

- 어드민 하위 작업에 적용되는 사용성 원칙이 문서화된다.
- 관련 게시글과 장소 사이를 자연스럽게 이동할 수 있다.
- 대시보드에 Cloudflare Access 또는 로그인 이메일이 노출되지 않는다.
- 기존 기능이 유지되며 `pnpm build`와 `./gradlew check`가 성공한다.

## 검증

- `pnpm build`
- `./gradlew check`
- dev 어드민 대시보드 및 게시글·장소 상호 이동 확인
