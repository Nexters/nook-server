# NOOK-190 그룹 상세 게시물 대표 미디어 선택 기준 수정

## 목적

그룹 상세의 게시물 목록에서 장소 썸네일 대신 Instagram 게시물에 포함된 첫 번째 이미지 또는 비디오를
`representativeMedia`로 반환합니다.

## 범위

- `GET /api/v1/groups/{groupId}/posts`의 대표 미디어 선택 기준을 게시물 미디어 순서로 변경합니다.
- 첫 번째 미디어의 타입, URL, 순서를 그대로 유지합니다.
- 장소 썸네일이 존재해도 그룹 상세 게시물 대표 미디어보다 우선하지 않도록 합니다.
- 장소 썸네일과 비디오가 함께 존재하는 회귀 테스트를 추가합니다.

## 제외 범위

- 일반 저장 게시물 목록의 대표 미디어 정책 변경
- 장소 상세 연관 게시물의 대표 미디어 정책 변경
- Instagram 미디어 저장 및 순서 결정 로직 변경
- DB 스키마 변경

## 검증

- 그룹 상세 목록이 첫 Instagram 비디오를 `VIDEO` 타입과 원본 URL로 반환하는지 검증합니다.
- 장소 썸네일 조회가 그룹 상세 목록에서 수행되지 않는지 검증합니다.
- `./gradlew check`
