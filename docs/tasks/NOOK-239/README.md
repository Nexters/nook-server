# NOOK-239 공유 아카이브 장소를 내 장소에 동기화

## 목적

공유 아카이브를 구독한 사용자가 원본 아카이브의 장소를 최근 저장 장소와 지도 장소에서도
확인할 수 있도록 한다. 공유 콘텐츠는 복제하지 않고 활성 구독을 장소 접근 근거로 사용한다.

## 범위

- 최초 구독 시 공유 아카이브의 기존 장소 북마크를 멱등 생성
- 공유 아카이브의 게시물에 이후 연결되는 장소를 활성 구독자에게 동기화
- 기존 장소가 포함된 게시물을 공유 아카이브에 추가할 때 활성 구독자에게 동기화
- 최근 장소와 지도 장소 조회에서 내 저장 게시물 또는 활성 공유 구독을 접근 근거로 인정
- 구독 해제, 링크 폐기·만료 시 다른 접근 근거가 없는 공유 장소 제외
- 기존 사용자 장소 북마크와 메모 보존

## 제외 범위

- 공유 아카이브 콘텐츠 복제
- 공유 콘텐츠 편집 권한 변경
- 기존 API endpoint와 응답 계약 변경
- 접근 근거가 사라진 북마크 행의 물리 삭제

## 정책

- `(user_id, place_id)` 유니크 제약과 `INSERT IGNORE`로 동기화를 멱등 처리한다.
- 기존 북마크는 다시 생성하거나 메모를 덮어쓰지 않는다.
- 장소 노출 여부는 조회 시점의 내 저장 게시물 또는 활성 공유 구독으로 결정한다.
- 구독 행이 삭제되거나 공유 링크가 폐기·만료되면 해당 공유 접근 근거는 즉시 사라진다.
- 같은 장소에 다른 내 게시물 또는 활성 공유 구독이 있으면 계속 노출한다.

## 성공 기준

- 공유 아카이브 저장 직후 기존 장소가 최근 장소와 지도 장소에 나타난다.
- 이후 추가된 장소와 기존 장소가 포함된 새 게시물도 활성 구독자에게 나타난다.
- 같은 장소는 여러 게시물이나 아카이브에 포함되어도 한 번만 나타난다.
- 구독 해제 후 다른 접근 근거가 있는 장소만 유지된다.
- 기존 장소 메모가 보존되고 cursor pagination 계약이 유지된다.
- `./gradlew check`가 통과한다.

## 검증

- 구독 및 그룹 게시물 변경 persistence 단위 테스트
- 장소 연결 및 파싱 persistence 단위 테스트
- 최근 장소와 지도 장소 query 및 cursor 계약 검증
- `./gradlew detekt`, `./gradlew test`, `./gradlew check`
