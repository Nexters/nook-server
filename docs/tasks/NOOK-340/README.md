# NOOK-340 어드민 대시보드 카드 반응형 배치

## 목적

어드민 대시보드 바로가기 카드의 폭과 줄바꿈을 개선해 각 관리 영역을 빠르게 식별할 수 있게 한다.

## 범위

- 넓은 화면에서 바로가기 카드를 행당 3개 표시한다.
- 중간 화면에서는 2개, 모바일에서는 1개씩 표시한다.
- 카드 높이와 하단 액션 위치를 행 안에서 일관되게 맞춘다.
- 기존 카드 문구, 아이콘 및 링크는 변경하지 않는다.

## 제외 범위

- 대시보드 정보 구조 및 메뉴 순서 변경
- 개별 관리 화면 디자인 변경

## 검증

- `pnpm --dir nook-admin-web build`
- `./gradlew check`
