# NOOK-284 어드민 파싱 파이프라인 및 규칙 탐색기

## 목적

운영자가 게시물 파싱 전 과정을 확대·이동 가능한 그래프로 탐색하고, 각 단계에서 실제로 적용되는
판정 규칙과 런타임 provider 설정을 한 화면에서 확인할 수 있게 한다.

## 범위

- 콘텐츠, 장소, 장소 사진 보강 파이프라인 그래프
- 노드별 입력·출력, 실행 조건, 임계값, 점수표, fallback, 예시 상세
- 모든 노드의 판정 순서, 조건식, 통과·불충족 결과와 실제 코드 출처
- 음절 유사도와 후보 점수처럼 계산이 필요한 규칙의 수식 및 계산 예시
- `runtime_configurations` 설정값과 실제 적용값 구분
- 게시글별 현재 마일스톤, 진행률, 시도 횟수, 실패 사유 표시
- 게시글별 콘텐츠·장소 파싱 실행 이력과 단계별 소요 시간 표시
- 장소 검색어, 검색 후보, 주소 호환·엄격 일치·근거 일치 판정 수와 후보 탈락 사유 표시
- 지역명이 붙은 추출 상호명과 지도 기본 상호명의 안전한 복구
- 게시글 상세에서 파이프라인 화면으로 이동
- 그래프 확대·축소·이동, 미니맵, 화면 맞춤

## 제외 범위

- 런타임 설정 수정
- 파싱 재처리
- provider 원문 응답과 secret 저장
- 사용자 원문, API key 및 secret 노출

## 검증

- 규칙 카탈로그와 런타임 설정 해석 단위 테스트
- `타바타 용산`과 지도 상호명 `타바타` 재현 및 오매칭 방지 회귀 테스트
- 실행 이력 저장 및 어드민 조회 통합 테스트
- 어드민 API 계약 테스트
- `pnpm --dir nook-admin-web build`
- `./gradlew check`
- 로컬 API와 어드민을 실행해 Chrome에서 주요 상호작용 확인

- `./gradlew check`: 성공
- `pnpm --dir nook-admin-web build`: 성공
- 게시물 475 재현 fixture로 로컬 어드민 실행: 성공
- 실패한 후보 판정 단계 확장 및 추출 단서·주소·후보 수·탈락 수·후보 목록 표시 확인
