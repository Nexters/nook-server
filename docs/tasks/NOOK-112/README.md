# NOOK-112 기존 게시물 재사용 시 장소 북마크 생성 누락 수정

## 목적

이미 장소 파싱이 완료된 게시물을 새로운 사용자가 저장할 때 기존 연관 장소를 해당 사용자의
기본 북마크 ON 상태로 생성한다.

## 문제

신규 장소 파싱 완료 경로는 저장한 사용자별로 `user_place_bookmarks`를 생성하지만, 이미 파싱이
완료된 게시물을 재사용하는 경로는 `user_saved_posts`와 그룹 연결만 생성한다. 파싱이 다시 실행되지
않으므로 새 사용자의 북마크 행이 생성되지 않고 모든 연관 장소가 OFF로 조회된다.

## 범위

- 기존 게시물을 처음 저장하는 사용자의 연관 장소 북마크 생성
- 사용자와 장소 기준 `INSERT IGNORE`를 통한 멱등성 유지
- 기존 사용자의 재저장 및 삭제 후 복구 시 현재 북마크 상태 보존
- 재사용 persistence 단위 테스트

## 제외 범위

- 기존 데이터 일괄 보정
- 데이터베이스 스키마 변경
- 북마크 API 계약 변경

## 성공 기준

- 파싱 완료된 기존 게시물을 처음 저장한 사용자의 모든 연관 장소가 북마크 ON이다.
- 이미 저장한 사용자가 같은 게시물을 다시 저장해도 기존 북마크 상태가 변경되지 않는다.
- 삭제한 저장 게시물을 복구해도 기존 북마크 상태가 변경되지 않는다.
- 다른 사용자의 북마크 상태에 영향을 주지 않는다.
- `./gradlew check`가 통과한다.
