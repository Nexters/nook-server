# NOOK-33 장소 상세 및 연관 게시물 목록 API

## 목적

지도에서 장소를 선택했을 때 장소 정보와 현재 사용자가 저장한 연관 게시물을 함께 조회할 수 있도록 합니다.

## 범위

- 장소명, 주소, 좌표, 카테고리, 전화번호와 provider 정보 조회
- 현재 사용자의 장소 북마크 상태 조회
- 현재 사용자가 저장한 연관 게시물 목록과 page 기반 pagination
- 게시물 제목, 작성자, 대표 미디어, 메모와 저장 시각 반환
- 저장 시각과 저장 게시물 ID 내림차순 정렬
- 검색어 기반 장소 후보 조회를 장소 파싱 worker의 내부 유스케이스로만 유지
- HTTP Client 요청과 OpenAPI 갱신

## 제외 범위

- 지도 viewport 장소 목록
- 장소 정보 직접 편집과 공용 장소 병합
- 장소 북마크 변경
- 데이터베이스 스키마 변경

## API

`GET /api/v1/places/{placeId}?page=0&size=20`

장소 상세와 `posts` 페이지를 한 응답으로 반환합니다. 장소 접근은 현재 사용자가 해당 장소를 북마크했거나,
해당 장소와 연결된 저장 게시물을 보유한 경우에만 허용합니다. 두 조건을 모두 만족하지 않으면 다른 사용자의
장소 사용 여부를 노출하지 않도록 `404 Not Found`로 처리합니다.

## 성공 기준

- 북마크한 장소는 연관 게시물이 없어도 조회할 수 있습니다.
- 북마크를 해제한 장소도 현재 사용자의 저장 게시물이 연결되어 있으면 조회할 수 있습니다.
- 다른 사용자의 저장 게시물과 메모는 응답에 포함되지 않습니다.
- 연관 게시물은 안정적인 정렬과 pagination 정보를 제공합니다.
- 장소 후보 검색 endpoint는 외부 API와 OpenAPI에 노출되지 않습니다.
- `./gradlew check`가 성공합니다.

## 검증
