# NOOK-242 Nook 디자인 시스템 기반 어드민 시각 개편

## 목적

React Admin과 MUI 기반 운영 어드민에 Nook 디자인 시스템의 색상과 타이포그래피를 적용하고 공통 화면의 시각적 위계를 정리한다.

## 범위

- SUIT 및 Roboto Mono 서체 적용
- Nook 컬러와 타이포그래피 MUI 테마 구성
- 사이드바, 헤더, 검색 필드, 버튼, 배지, 테이블, 카드, 다이얼로그 스타일 개선
- Dashboard, 게시글, 장소, 감사 로그 화면의 시각적 위계 개선

## 제외 범위

- 관리자 API 계약 변경
- 게시글 및 장소 관리 기능 변경
- 메뉴 정보 구조 변경

## 성공 기준

- 전체 어드민에 Nook 색상과 서체가 일관되게 적용된다.
- 목록과 상세 화면의 제목, 상태, 보조 정보, 행동 요소가 명확히 구분된다.
- 기존 관리 기능이 동일하게 동작한다.
- `pnpm build`와 `./gradlew check`가 성공한다.
- dev 어드민의 주요 화면이 콘솔 오류 없이 표시된다.

## 검증

- `pnpm build`
- `./gradlew check`
- dev 어드민 Dashboard, 게시글 목록·상세, 장소 목록·상세, 감사 로그 확인
