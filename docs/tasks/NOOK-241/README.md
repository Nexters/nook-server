# NOOK-241 어드민 게시글·장소 상세 진입 오류 수정

## 목적

어드민 목록에서 게시글이나 장소를 클릭했을 때 상세 화면이 클라이언트 오류로 중단되는 문제를 수정한다.

## 범위

- 게시글 상세 데이터가 로드되기 전 목록 요약 레코드를 안전하게 처리한다.
- 장소 상세 데이터가 로드되기 전 목록 요약 레코드를 안전하게 처리한다.

## 제외 범위

- 관리자 API 계약 변경
- 상세 화면 UI 개편
- 프론트엔드 테스트 프레임워크 도입

## 성공 기준

- 게시글 목록에서 상세로 진입하면 상세 내용과 장소 매핑이 표시된다.
- 장소 목록에서 상세로 진입하면 상세 내용과 연결 게시글이 표시된다.
- `nook-admin-web`의 `pnpm build`와 저장소의 `./gradlew check`가 성공한다.

## 검증

- `pnpm build`
- `./gradlew check`
- dev 어드민에서 게시글 및 장소 상세 진입 확인
