# NOOK-203 어드민 게시글·장소 매핑 교정 및 범용 감사 로그 구현

## 목적

Cloudflare Access로 인증된 운영자가 파싱된 게시글과 장소를 검수하고, 잘못된 공용 장소
매핑을 기존 사용자 데이터에 영향을 주지 않으면서 교정할 수 있게 한다. 모든 관리자 변경은
범용 감사 로그에 변경 전후 값과 사유를 남긴다.

## 범위

- `/api/admin/v1/**` Cloudflare Access JWT 검증 및 관리자 actor 제공
- Access JWT의 검증된 `sub`, `email`을 감사 주체로 사용
- 범용 append-only 감사 로그 스키마와 application 포트 구현
- 게시글 목록/상세 및 파싱 상태·실패 사유 조회
- 장소 검색과 공용 `post_places` 매핑 연결·해제·순서 변경
- 기존 `user_saved_post_places`는 변경하지 않고 이후 저장 건에만 교정 결과 적용
- 관리자 교정 결과를 재파싱이 덮어쓰지 않도록 보호
- React Admin 게시글 검수·매핑 교정·감사 로그 화면 연결
- 관리자 API용 HTTP Client 요청 파일과 테스트 추가

## 제외 범위

- 기존 사용자별 장소 매핑 일괄 변경
- 사용자가 직접 수정한 매핑 덮어쓰기
- 장소 병합
- provider 원본 장소 정보 직접 수정
- live Cloudflare Access 애플리케이션/정책 생성 또는 변경
- 감사 로그 수정·삭제 API

## 성공 기준

- 유효한 Access JWT의 운영자만 관리자 API를 호출할 수 있다.
- 공용 장소 매핑을 교정해도 기존 사용자의 저장 장소는 유지된다.
- 이후 새로 저장한 사용자에게는 교정된 매핑이 적용된다.
- 모든 관리자 변경은 운영자 이메일, 사유, 변경 전후 값과 함께 같은 트랜잭션에서 기록된다.
- 관리자 교정 결과는 재파싱으로 덮어쓰이지 않는다.

- 공용 매핑 교정과 사용자 스냅샷 보존 통합 테스트
- 관리자 조회 및 교정 controller 테스트
