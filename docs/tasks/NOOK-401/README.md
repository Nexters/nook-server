# 같은 장소를 새 게시물에서 저장하면 최근 저장 순서 갱신

## 목적

같은 사용자가 여러 저장 게시물에 연결한 장소는 가장 최근 게시물에서 저장된 시각을 기준으로 최근 저장 장소 목록에 표시한다.

## 범위

- 장소 북마크에 마지막 저장 연결 시각을 별도로 기록한다.
- 새 저장 게시물의 장소 파싱 및 기존 게시물에 대한 장소 수동 연결에서 시각을 갱신한다.
- 최근 장소 목록 정렬, 커서 페이지네이션과 조회 인덱스를 새 시각 기준으로 변경한다.
- 기존 북마크 메모와 감사용 `created_at`은 유지한다.

## 제외 범위

- 공개 API 응답 필드 또는 커서 형식 변경
- 직접 북마크 켜기/끄기 동작 변경
- 장소·게시물 데이터 정리

## 검증

- 같은 장소가 여러 게시물에서 저장될 때 마지막 연결이 최근 목록 상단에 오는지 검증한다.
- 중복 저장 관계를 처리해도 북마크와 사용자 메모가 중복 생성·덮어쓰기 되지 않는지 검증한다.
- cursor 조회가 `last_saved_at`, `id` 순으로 안정적인지 검증한다.
- 관련 최근 장소 조회·파싱·저장 테스트와 `./gradlew detekt` 통과
- `./gradlew clean check`는 기존 `ParsingSummaryMySqlTest`의 legacy fingerprint 단언 실패로 전체 통과하지 못함. 이 테스트는 파싱 알림을 다루며 이번 변경 파일과 무관하고 단독 재실행에서도 동일하게 실패함.

## 배포 및 롤백

`ddl/up.sql`로 기존 `created_at`에서 `last_saved_at`을 채우고 조회 인덱스를 교체한 뒤 애플리케이션을 배포한다. 롤백 시 애플리케이션을 이전 버전으로 되돌린 후 `ddl/rollback.sql`로 인덱스와 칼럼을 복구한다. 작업 문서에 실제 적용 일시와 실행자를 기록한다.
