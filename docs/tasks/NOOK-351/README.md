# NOOK-351 파싱 회차 격리와 복구 정책

## 진행 범위

콘텐츠·장소·후속 작업에 같은 오류 분류기를 주입한다.
HTTP 429는 Retry-After를 반영하고, 인증/권한 오류와 400/404/410/422는 자동 재시도를 종료한다.
5xx와 네트워크 오류는 재시도하며 분류할 수 없는 오류도 기존 제한 횟수 내에서 재시도한다.
Retry-After는 초 또는 HTTP-date를 읽고 0~30분으로 제한한다.
이는 작업별 지연이며 provider 전체의 동시 요청 제한 기능은 아니다.

## 미구현 및 결정 대기

전체 재분석에서 기존 자동 장소 연결을 교체할지 새 장소를 누적할지 사용자 결정이 필요하다.
사용자 저장 장소와 관리자 교정 내용을 보존한다는 원칙은 공통이다.
선택 이후 회차 식별, 이전 회차 결과 차단, 본체 작업 입력 교체, 회차별 재시도 횟수,
수동 교정 및 전역 장소 썸네일 보호를 구현하고 검증한다. 현재 완료된 기능으로 간주하지 않는다.
