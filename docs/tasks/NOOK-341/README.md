# NOOK-341 수동 등록 장소 파싱 fallback

## 목적

외부 장소 검색에서 게시물의 장소 단서와 호환되는 후보를 찾지 못했을 때 수동 등록 장소를
최후 fallback으로 조회해 외부 지도에 등록되지 않은 장소도 파싱 결과에 연결한다.

## 범위

- 기존 외부 Provider 검색 순서를 유지한다.
- 외부 검색 결과에 호환 후보가 없을 때만 `MANUAL` 장소를 이름으로 조회한다.
- 수동 장소도 기존 이름·지역·주소 후보 판정 정책을 동일하게 통과해야 한다.
- fallback 검색 여부와 후보 수를 처리 트레이스에 기록한다.
- 운영 DB의 게시물 791 및 직접 참조하는 종속 데이터를 정리한다.

## 제외 범위

- 수동 장소 우선 검색
- 기존 실패 게시물의 일괄 재처리
- 수동 등록 장소 `매미지옥` 삭제
- 관리자 감사 로그 삭제

## 검증

- 외부 호환 후보가 있으면 수동 장소를 조회하지 않는다.
- 외부 호환 후보가 없고 수동 장소가 기존 판정 정책을 통과하면 연결한다.
- 후보가 없거나 모호하면 기존 실패 동작을 유지한다.
- `./gradlew check`
