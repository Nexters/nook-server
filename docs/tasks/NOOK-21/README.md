# NOOK-21 OpenAI 기반 게시물 제목 및 복수 장소 추출 연동

## 목적

Instagram 게시물 정보로 제목을 생성하고, 비동기로 복수 장소를 추출해 카카오 장소 정보로 저장한다.

## 범위

- `gpt-5-nano` Responses API Structured Outputs 연동
- 게시물 저장 전 사실 기반의 검색·보관용 제목 동기 생성
- 사용자가 입력한 Instagram URL과 쿼리 파라미터 원문 저장
- 저장 후 장소 파싱 작업 비동기 실행
- URL 요청마다 별도의 게시물과 선택 메모 생성
- 게시물당 최대 10개 장소 단서 추출
- 카카오 장소 검색 결과가 하나로 식별되는 장소 저장
- 장소는 공용으로 재사용하고 게시물 장소 관계는 기본 북마크로 생성
- 연관 장소 관계를 유지하는 북마크 ON/OFF API
- 장소 파싱 상태와 실패 사유 관리

## 제외 범위

- OCR과 이미지·영상 분석
- 사용자의 장소 후보 선택
- 카카오 외 지도 provider
- 고성능 모델 fallback
- 미디어 S3 저장

## 성공 기준

- Instagram 저장 응답 전에 생성된 제목이 게시물에 저장된다.
- 장소 파싱은 저장 트랜잭션 밖에서 비동기로 실행된다.
- 여러 장소가 추출되면 `places`와 `post_places`에 순서대로 저장된다.
- 같은 Instagram URL을 저장해도 매번 별도 게시물이 생성된다.
- 장소 북마크를 해제해도 게시물과 장소의 연관 관계는 유지된다.
- 근거가 없는 게시물은 장소 없이 완료된다.
- 장소를 하나로 식별하지 못하거나 provider 호출이 실패하면 작업이 실패 처리된다.
- `./gradlew check`가 성공한다.

## 검증

```shell
./gradlew check
```
