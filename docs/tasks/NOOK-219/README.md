# NOOK-219 Instagram 게시물 제목과 장소 원문 일관성 개선

## 목적

Instagram 원문에 없는 고유명사가 제목 생성 프롬프트의 예시에서 복사되어 게시물 제목으로
저장되는 문제를 방지하고, 첫 번째 이미지에 명시적인 표지 제목이 있으면 이를 우선 사용합니다.
본문에 장소 단서가 충분한 경우 불필요한 이미지 OCR을 실행하지 않으며, 장소 썸네일은 고정
폴백 이미지가 아니라 해당 게시물의 장소별 미디어를 사용합니다.

## 범위

- 제목 생성 프롬프트의 `홍별감네 외 맛집 5곳` 예시를 `방문해보기 좋은 곳`으로 교체합니다.
- 장소나 지역 정보가 부족할 때 입력에 없는 고유명사를 생성하지 않도록 지침을 명확히 합니다.
- 첫 번째 미디어가 이미지이면 표지의 날짜·회차 라벨과 중앙 제목을 별도로 전사합니다.
- 표지 제목이 확인되면 줄바꿈만 정리해 본문 기반 생성 제목보다 우선 사용합니다.
- 이미지에 표지 제목이 없거나 이미지가 없으면 본문 기반 제목 생성을 유지합니다.
- 프롬프트에서 기존 고유명사 예시가 제거됐는지 검증하는 회귀 테스트를 추가합니다.
- OCR 보강 여부는 지도 후보 매칭 성공 개수가 아니라 본문에서 추출한 장소 단서 개수로 판단합니다.
- 본문 장소 단서가 전혀 지도 후보로 확정되지 않은 경우에는 기존처럼 이미지 OCR을 수행합니다.
- 표지 1장과 장소 이미지 N장인 게시물은 표지를 건너뛰고 장소 순서에 맞는 이미지를 선택합니다.
- 선택한 Instagram 미디어는 기존 미디어 저장 포트를 통해 버킷에 저장한 뒤 장소 썸네일로 사용합니다.
- 기존 고정 폴백 URL과 정확히 일치하는 장소 썸네일만 게시물 미디어로 교체합니다.
- 동일 장소를 여러 원본 게시물이 포함해도 사진이 섞이지 않도록 사용자 저장 게시물-장소 관계에
  해당 원본 게시물의 장소 이미지를 저장하고 상세·파싱 응답에서 우선 사용합니다.

## 제외 범위

- 장소 후보의 한글·영문 상호명 매칭 개선
- Google Places 사진 연동 재활성화
- OCR 모델 또는 프롬프트 변경
- 기존 데이터 전체의 장소별 원본 이미지 재추론 및 일괄 보정

## 성공 기준

- 제목 생성 프롬프트에 `홍별감네`가 존재하지 않습니다.
- 일반 제목 예시로 `방문해보기 좋은 곳`을 사용합니다.
- 첫 이미지에 표지 제목이 있으면 해당 문구에 근거한 제목을 생성합니다.
- 이미지가 없는 요청은 기존 텍스트 기반 제목 생성을 유지합니다.
- 본문에 예상 장소 수만큼 단서가 있으면 일부 장소가 지도에서 확정되지 않아도 OCR을 실행하지 않습니다.
- 새 장소 썸네일이 한 개의 고정 이미지로 통일되지 않고 게시물의 장소별 이미지와 대응합니다.
- 고정 폴백이 아닌 기존 장소 썸네일은 덮어쓰지 않습니다.
- 관련 테스트와 `./gradlew check`가 성공합니다.
