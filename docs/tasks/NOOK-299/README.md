# NOOK-299 외부 API SKU별 상한·Slack 단계 알림 및 사용량 시각화

## 목적

외부 API SKU별 월간 호출량 또는 USD 예상 비용 상한을 설정하고 50%, 80%, 95%, 100% 도달 시
Slack으로 중복 없이 알린다. 어드민에서는 무료 quota와 과금 구간, 상한 소진율을 함께 표시한다.

## 범위

- SKU별 `CALLS`, `COST_USD` 월 상한 조회·설정
- 월·정책·임계치별 Slack 발송 이력과 재시도
- 가격 정책 기준 무료 quota, 과금 사용량, 예상 비용 조회
- 호출 이력이 없는 SKU 포함
- SKU별 진행 막대와 상한 설정 UI

## 제외 범위

- 100% 도달 시 자동 차단
- Slack webhook 원문 저장 또는 노출
- 라이브 DB 적용

## 성공 기준

- 50%, 80%, 95%, 100% 알림이 월별로 각각 한 번만 성공 처리된다.
- Slack 전송 실패는 발송 완료로 기록되지 않는다.
- 무료 quota와 상한 소진율을 SKU별로 확인할 수 있다.
- `./gradlew check`와 `pnpm --dir nook-admin-web build`가 통과한다.
