# NOOK-339 어드민 장소 수동 등록

## 목적

관리자가 외부 장소 검색 결과에 의존하지 않고 장소명과 주소를 직접 입력해 공개 장소를 등록한다.

## 범위

- `POST /api/admin/v1/places` API를 추가한다.
- 장소 관리 목록에서 장소 추가 버튼과 직접 입력 폼을 제공한다.
- 카카오 주소 검색으로 입력 주소를 검증하고 도로명 주소를 우선 정규화한다.
- 주소에서 WGS84 위도와 경도를 자동으로 채운다.
- 장소의 선택 정보와 생성 감사 로그를 저장한다.
- 정규화된 장소명, 주소, 좌표가 같은 장소의 중복 등록을 막는다.

## 제외 범위

- 관리자 인증 및 권한 체계 변경
- 장소 승인 또는 비공개 상태 추가
- 외부 장소 검색 결과 기반 자동 등록

## API 계약

- 필수 요청값: `name`, `address`, `reason`
- 선택 요청값: `category`, `phoneNumber`, `thumbnailUrl`, `photoUrls`, `representativeTags`, `openingHours`
- `address`는 완전한 도로명 주소 또는 지번 주소를 입력한다.
- 정확히 하나의 주소로 변환되지 않으면 등록하지 않는다.
- 생성된 장소의 provider는 `MANUAL`이며 즉시 기존 장소 조회에 노출된다.
- 주소 입력란에는 완전한 도로명 또는 지번 주소 형식과 예시를 안내한다.

## 데이터베이스

기존 `places` 스키마와 `(provider, external_place_id)` 유니크 인덱스를 사용하므로 별도 DDL은 없다.
수동 장소의 external place id는 정규화된 이름, 주소, 좌표의 SHA-256 식별자로 생성한다.
