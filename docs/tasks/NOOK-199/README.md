# NOOK-199 파싱 실패 게시물을 그룹 목록과 상세에서 유지

## 목적

장소가 연결되지 않았거나 콘텐츠·장소 파싱이 실패하더라도 사용자가 저장한 게시물을
아카이브에서 계속 조회하고 상세 화면에 진입할 수 있도록 합니다.

## 범위

- 그룹 게시물 목록에서 콘텐츠 파싱 실패 게시물을 제외하는 조건을 제거합니다.
- 그룹 목록 및 그룹 상세의 게시물 수에 모든 활성 저장 게시물을 포함합니다.
- 장소 연결이 없는 게시물 상세는 저장된 원문 정보와 빈 장소 목록을 반환합니다.
- 실패 상태는 기존 처리 상태 필드로 전달합니다.
- 콘텐츠·장소 파싱 실패 게시물의 목록 및 상세 회귀 테스트를 추가합니다.

## 제외 범위

- 콘텐츠·장소 파싱 재시도 정책 변경
- 파싱 실패 원인 또는 상태 enum 변경
- 장소 자동 연결 정확도 개선
- 기존 API 경로 및 응답 필드 변경
- DB 스키마 변경

## 성공 기준

- 콘텐츠 파싱 실패 게시물이 그룹 게시물 목록과 게시물 수에 포함됩니다.
- 장소 파싱 실패 또는 장소가 0개인 저장 게시물이 그룹 목록에 표시됩니다.
- 해당 게시물 상세 조회가 저장된 원문 정보와 `places: []`를 반환합니다.
- 목록의 `postId`로 상세 조회할 수 있습니다.
- `./gradlew check`가 통과합니다.
