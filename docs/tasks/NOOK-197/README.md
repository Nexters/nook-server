# NOOK-197 직접 연결 장소의 썸네일 파싱 상태 불일치 수정

## 목적

장소를 게시물에 직접 연결했을 때 썸네일 URL은 저장됐지만 `thumbnailParsingStatus`가
`PENDING`으로 유지되는 불일치를 수정합니다.

## 범위

- 직접 장소 연결에서 썸네일 보강 결과를 저장할 때 상태도 `COMPLETED`로 갱신합니다.
- 게시물 장소 파싱, 저장 게시물 상세, 장소 상세 응답은 썸네일 URL이 존재하면
  `thumbnailParsingStatus=COMPLETED`를 반환합니다.
- 기존 불일치 데이터를 보정하는 멱등 DML을 제공합니다.
- 직접 연결 저장과 응답 상태 산정 회귀 테스트를 추가합니다.

## 제외 범위

- 썸네일 provider 정책 변경
- Google 장소 사진 또는 고정 fallback 재활성화
- API 필드나 상태 enum 변경
- 썸네일 재시도 큐 신설

## 성공 기준

- 직접 연결로 썸네일 URL이 저장된 장소의 상태가 `COMPLETED`입니다.
- 세 장소 응답에서 썸네일 URL과 상태가 모순되지 않습니다.
- URL이 없는 실제 처리 중 장소는 기존 상태를 유지합니다.
- 기존 데이터 보정 DML이 반복 실행되어도 결과가 같습니다.
- `./gradlew check`가 성공합니다.
