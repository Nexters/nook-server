# NOOK-252 Apify Google 장소 사진 오매칭 방지

## 목적

Apify Google Maps 사진 검색 결과가 실제 저장 장소와 다른 업체일 때 사진과 Google Place ID가
잘못 저장되지 않도록 장소 매칭 조건을 강화한다.

## 원인

직접 추가한 `음`은 음식점이며 주소는 `충북 청주시 상당구 남사로102번길 8`이다. 기존 로직은
검색 결과를 하나만 받고 이름과 주소가 모두 달라도 좌표가 300m 이내면 허용했다. 이 때문에 약
215m 떨어진 `정감호텔`의 사진 6장과 Google Place ID가 `음`에 저장됐다.

## 범위

- 검색당 후보를 최대 5개까지 조회
- Google Place ID가 이미 있으면 일치 후보 우선 선택
- 정확한 주소 또는 이름 일치와 300m 이내 좌표를 조합해 후보 검증
- 한 글자 장소명은 정확한 도로명과 번지 일치 필수
- 이름과 주소 조건이 비슷하면 상위 카테고리가 일치하는 후보 우선
- 적합한 후보가 없으면 사진 없이 종료
- 오매칭 재현 및 정상 후보 선택 회귀 테스트 추가

## 제외 범위

- 기존 dev 장소 데이터 정정
- 장소 검색 provider 변경
- 공개 API 및 데이터베이스 스키마 변경
- 클라이언트 변경

## 성공 기준

- `음`이 `정감호텔`과 매칭되지 않는다.
- 여러 결과 중 주소와 카테고리가 일치하는 `음` 음식점을 선택한다.
- 이름과 주소가 충분히 일치하면 카테고리 충돌만으로 후보를 제외하지 않는다.
- 한글과 영문 표기가 달라도 도로명과 번지가 같은 기존 정상 장소는 계속 매칭된다.
- Google Place ID가 정확히 일치하는 기존 흐름을 유지한다.
- `./gradlew check`가 성공한다.

## 검증

- `./gradlew :nook-api-infrastructure:test --tests '*ApifyGoogleMapsPhotoProviderTest'`
- `./gradlew detekt`
- `./gradlew check`

## 배포 및 롤백

스키마와 공개 API 변경은 없다. 애플리케이션만 배포하며 문제가 생기면 이전 버전으로 롤백한다.
기존 dev 장소 ID `1000`에 저장된 잘못된 Google Place ID와 사진은 별도 운영 작업으로 정정한다.
