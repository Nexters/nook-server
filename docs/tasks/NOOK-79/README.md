# NOOK-79 동일 그룹명 허용 및 게시물 중복 저장 정책 정합성 보완

## 목적

동일 사용자가 같은 이름의 그룹을 여러 개 만들 수 있게 하고, 동일 게시물은 그룹별로 한 번만
노출하면서 여러 그룹에 연결할 수 있는 기존 저장 정책을 유지한다.

## 범위

- 동일 사용자의 같은 이름 그룹 생성 허용
- 그룹 수정 시 다른 기존 그룹과 같은 이름 허용
- 그룹명 중복 오류 분기와 영속성 검사 제거
- `user_groups`의 `(user_id, name)` 유니크 인덱스 제거
- 그룹 생성·수정과 게시물 그룹 연결 회귀 테스트
- OpenAPI 오류 코드 예시 갱신

## 제외 범위

- 그룹 식별 방식 변경
- 게시물 재저장 시 기존 메모 덮어쓰기
- 같은 게시물의 같은 그룹 내 복수 노출
- 기존 그룹 또는 게시물 데이터 병합

## 저장 정책

그룹은 이름이 같아도 서로 다른 `groupId`로 식별한다. 게시물 재저장은 기존 사용자 저장 게시물을
재사용하고, 아직 연결되지 않은 그룹만 추가한다. `group_posts`의
`(group_id, user_saved_post_id)` 유니크 제약은 유지한다.

## 성공 기준

- 같은 사용자가 동일한 이름의 그룹을 서로 다른 `groupId`로 생성할 수 있다.
- 그룹명을 다른 기존 그룹과 같은 이름으로 수정할 수 있다.
- 같은 게시물을 같은 그룹에 반복 저장해도 한 번만 목록에 노출된다.
- 동일 게시물을 여러 그룹에 연결할 수 있다.
- `./gradlew check`가 성공한다.

## 검증

```shell
./gradlew detekt
./gradlew test
./gradlew check
```
