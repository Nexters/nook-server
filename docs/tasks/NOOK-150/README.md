# NOOK-150 이미지 전사 기반 장소 파싱과 게시물 제목 사실성 개선

## 목적

카드뉴스 이미지를 소규모 묶음으로 전사하고 전사 결과를 DB에 저장한 뒤 텍스트 기반으로 장소 단서를
생성한다. 본문에 명시된 지역, 업종과 장소 개수를 제목의 우선 사실로 사용해 제목 왜곡도 방지한다.

## 범위

- 최대 20개 이미지를 요청당 5개 이하로 나눈 OpenAI 고해상도 원문 전사
- 이미지 순번별 전사 결과를 `place_parsing_jobs.image_transcripts`에 JSON으로 저장
- 재시도 시 저장된 이미지 전사를 재사용하고 Vision 호출 생략
- 저장된 전사, 본문, 해시태그와 장소 태그를 사용한 text-only 장소 단서 생성
- 장소 단서 및 본문 기대 장소 개수 상한을 20개로 확장
- 이미지 근거와 카카오 후보 상호명 또는 주소의 일치 검증
- 본문의 명시적 `지역 + 업종 + 개수` 제목 우선 적용

## 제외 범위

- Naver OCR 등 별도 OCR provider
- OpenAI 모델 변경
- 공개 API 계약 변경
- 이미지 레이아웃 또는 이미지당 장소 개수 가정

## 성공 기준

- Vision 요청 하나에 이미지가 5개를 넘지 않고 전체 이미지 순번이 유지된다.
- 저장된 전사가 있으면 장소 worker 재시도에서 Vision 요청을 반복하지 않는다.
- 최대 20개 장소를 반환하고 본문의 `19곳`을 기대 개수로 인식한다.
- `감도 좋은 서울 카페 19곳` 본문의 제목은 `서울 카페 19곳`이다.
- 이미지 근거와 일치하지 않는 카카오 후보는 저장되지 않는다.
- Post 131과 135를 dev에서 재처리해 결과를 확인한다.
