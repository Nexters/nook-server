# NOOK-223 장소 상세 저장 게시물 썸네일을 원본 대표 미디어로 반환

## 목적

장소 상세의 저장 게시물 목록에서 동일한 장소 썸네일이 반복되지 않고 각 인스타 게시물의 대표 미디어가 표시되게 한다.

## 범위

- `GET /api/v1/places/{placeId}` 응답의 `posts.items[].representativeMedia`를 각 원본 게시물의 첫 번째 미디어로 반환한다.
- 장소 자체의 `thumbnailUrl`은 기존처럼 장소 대표 이미지로 유지한다.
- 장소 썸네일이 존재하더라도 저장 게시물 대표 미디어를 덮어쓰지 않도록 회귀 테스트를 추가한다.
- 공유 그룹의 장소 상세처럼 동일 조회 어댑터를 사용하는 경로도 같은 정책을 적용한다.

## 제외 범위

- 게시물 원본 미디어 재파싱
- 장소 썸네일 생성 및 저장 정책 변경
- `GET /api/v1/posts` 전체 저장 게시물 목록의 기존 썸네일 정책 변경
- DB 스키마 및 데이터 변경

## 성공 기준

- 하프하우스에 연결된 저장 게시물 3건이 각각 서로 다른 원본 대표 이미지를 반환한다.
- 장소의 `thumbnailUrl`과 게시물의 `representativeMedia`가 독립적으로 유지된다.
- 원본 미디어가 없는 게시물은 다른 게시물이나 장소의 이미지로 대체되지 않는다.
- 관련 테스트와 `./gradlew check`가 성공한다.
