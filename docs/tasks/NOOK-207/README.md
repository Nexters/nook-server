# NOOK-207 내 저장 장소 문자열 검색 API 제공

## 목적

사용자가 자신이 저장한 장소 안에서 상호명·주소·카테고리 문자열로 원하는 장소를 검색할 수 있도록 합니다.

## 범위

- 인증 필수 `GET /api/v1/places/saved/search` API를 추가합니다.
- `query`, `page`, `size` 요청 파라미터를 제공합니다.
- 현재 북마크되어 있고 삭제되지 않은 내 저장 게시물과 연결된 장소만 검색합니다.
- 장소명, 주소, 카테고리의 부분 문자열을 매칭합니다.
- 응답 항목에 장소 `id`, `name`, `address`, `category`를 제공합니다.
- 사용자 격리, 검색어 검증, 페이지네이션 회귀 테스트와 HTTP Client 예시를 추가합니다.

## 제외 범위

- 외부 장소 provider 검색
- 초성·형태소·유사어·오타 보정 검색
- 전문 검색 엔진 또는 검색 인덱스 도입
- 북마크되지 않은 연관 장소 검색
- DB 스키마 변경

## 성공 기준

- 상호명, 주소, 카테고리 중 하나에 검색 문자열이 포함되면 결과에 노출됩니다.
- 다른 사용자의 장소와 북마크 해제된 장소는 노출되지 않습니다.
- 결과가 `id`, `name`, `address`, `category`를 포함합니다.
- 빈 검색어와 허용 범위를 벗어난 페이지 요청이 거절됩니다.
- `./gradlew check`가 통과합니다.
