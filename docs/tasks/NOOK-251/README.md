# NOOK-251 공유 아카이브 장소 검색 누락 수정

## 목적

공유 아카이브를 저장한 사용자가 공유 장소를 내 장소 검색에서도 찾을 수 있도록 한다.

## 범위

- 그룹 필터가 없는 내 장소 검색에서 활성 공유 구독을 장소 접근 근거로 인정
- 공유 링크 폐기·만료, 구독 해제 및 공유 게시물 삭제 상태 반영
- 기존 개인 저장 장소 검색과 내 그룹 필터 계약 유지
- 검색 본문과 count 쿼리에 동일한 접근 조건 적용

## 제외 범위

- API endpoint 및 응답 계약 변경
- 공유 아카이브 콘텐츠 복제
- 검색 그룹 목록에 공유 아카이브 추가
- 특정 내 그룹 필터 결과에 공유 장소 추가

## 성공 기준

- 활성 공유 아카이브의 장소가 그룹 필터 없는 내 장소 검색에 나타난다.
- 공유 접근 근거가 사라지면 공유 장소가 검색되지 않는다.
- 특정 내 그룹 필터는 해당 사용자가 소유한 그룹의 장소만 반환한다.
- 검색 결과와 전체 개수가 같은 접근 조건을 사용한다.
- `./gradlew check`가 통과한다.

## 검증

- 검색 SQL 접근 조건 회귀 테스트
- `./gradlew detekt`, `./gradlew test`, `./gradlew check`
