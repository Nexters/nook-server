# NOOK-144 다중 장소 게시물의 장소 단서 검증과 이미지 보강 개선

## 목적

텍스트 장소 단서가 게시물의 본문, 해시태그 또는 Instagram 장소 태그에 실제로 근거하는지 검증하고,
게시물에 명시된 장소 수보다 텍스트 확정 결과가 부족하면 저장된 이미지를 분석해 장소 누락과 오탐을 줄입니다.

## 범위

- 텍스트 장소 단서의 상호명 또는 검색어가 원본 텍스트에 존재하는지 검증
- 근거 없는 텍스트 단서는 장소 provider 검색 전에 제외
- 본문의 `10선`, `5곳`, `3군데`처럼 장소 수가 명확한 2~10개 기대 장소 수 감지
- 유효한 텍스트 결과가 없거나 기대 장소 수보다 부족할 때 이미지 분석 실행
- 이미지 번호와 근거 문구가 유효한 이미지 장소 단서만 후보 검색에 사용
- 텍스트와 이미지 장소를 provider 및 외부 장소 식별자로 중복 제거
- 이미지 보강 판단 근거와 제외된 단서를 로그로 관측

## 제외 범위

- OpenAI 모델 변경
- 장소 provider 변경
- 공개 API 계약 변경
- 범용 관리자 재처리 API
- 사용자 북마크 출처 스키마 변경

## 성공 기준

- 입력에 없는 장소 단서는 provider 검색 및 저장 대상에서 제외됩니다.
- 기대 장소 수보다 텍스트 확정 결과가 부족하면 이미지 분석이 실행됩니다.
- 이미지 분석 결과는 기존 텍스트 결과와 합쳐지고 같은 provider 장소는 한 번만 저장됩니다.
- 명시적인 단일 장소가 텍스트에서 확정되면 이미지 호출을 생략합니다.
- 기존 polling 상태와 오류 의미를 유지합니다.
- `./gradlew check`가 통과합니다.

## 검증

- 근거 있는 단서와 근거 없는 단서 필터링 테스트
- 기대 장소 수 충족 및 미충족 이미지 fallback 테스트
- 텍스트와 이미지 결과 병합 및 중복 제거 테스트
- 단일 장소 및 provider 실패 회귀 테스트
- `./gradlew detekt`
- `./gradlew test`
- `./gradlew check`
