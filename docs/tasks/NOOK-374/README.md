# NOOK-374 어드민 사용자 분석 계산 성능 개선

## 목적

분석 기간의 가입 사용자마다 전체 이벤트를 다시 검색하고, 날짜마다 전체 이벤트를 반복 집계하는
계산 구조를 제거한다.

## 범위

- 이벤트를 회원별로 한 번 인덱싱해 activation을 계산한다.
- 가입, 활성화, 활성 사용자를 날짜별로 한 번 집계한 뒤 일별 결과를 생성한다.
- 회원별 재방문 날짜 집합을 만들고 retention을 상수 시간 조회로 계산한다.
- DAU, WAU, MAU 계산에서 날짜·회원 집합을 재사용한다.
- 기존 분석 지표 정의와 결과를 유지한다.

## 제외 범위

- 분석 지표 정의와 API 계약 변경
- DB 집계 테이블 또는 캐시 도입
- 관리자 화면 변경

## 성공 기준과 검증

- activation 계산이 가입 사용자 수와 전체 이벤트 수의 곱으로 증가하지 않는다.
- retention 계산에서 회원마다 전체 이벤트를 검색하지 않는다.
- 기존 분석 결과 테스트와 대용량 입력 회귀 테스트가 성공한다.
- `./gradlew check`가 성공한다.
