# NOOK-244 어드민 사용자 노출 데이터 관리 범위 확장

## 목적

사용자 커스텀 데이터를 제외한 게시글·장소 공용 데이터를 이미지와 함께 검수하고 수정할 수 있게 한다.

## 범위

- 카카오·네이버 provider 브랜드 배지
- 게시글 미디어 및 장소 썸네일·사진 조회
- 게시글 제목, 작성자, 본문, 위치 태그, 해시태그, 미디어 수정
- 장소 이름, 주소, 도시, 카테고리, 전화번호, 이미지, 대표 태그, 영업시간 수정
- 수동 수정 게시글의 자동 파싱 덮어쓰기 방지
- 수정 사유 및 변경 전후 감사 로그
- 목록 검색 영역, 셀 패딩, 행 높이, 긴 주소와 가로 스크롤 개선

## 제외 범위

- 사용자별 장소명, 메모, 그룹 등 커스텀 데이터
- 이미지 파일 직접 업로드
- 위도와 경도, provider 식별자 수정

## 성공 기준

- 운영자가 사용자 노출 공용 데이터와 사진을 확인하고 수정할 수 있다.
- 수동 수정된 게시글은 이후 자동 콘텐츠 갱신으로 덮어쓰지 않는다.
- 모든 수정에 사유가 필요하고 감사 로그가 남는다.
- `pnpm build`와 `./gradlew check`가 성공한다.

## 검증

- `pnpm build`
- `./gradlew check`
- dev Chrome에서 목록과 게시글·장소 상세 및 수정 다이얼로그 확인
