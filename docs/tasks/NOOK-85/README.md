# NOOK-85 OpenAI 이미지 장소 추출 정확도 및 근거 보강

## 목적

NOOK-39의 이미지 fallback이 사람이 읽을 수 있는 장소 소개 이미지에서도 빈 결과를 반환하는 문제를
개선한다. 특정 카드뉴스 레이아웃이나 이미지당 장소 개수를 가정하지 않고, 이미지에서 관찰한 텍스트
근거를 장소 단서와 함께 전달한다.

## 범위

- 이미지 보강 요청의 모든 이미지에 `detail: high` 적용
- 이미지 전체 영역의 가독 가능한 텍스트를 대상으로 하는 레이아웃 독립적 추출 지시
- 한 이미지에서 장소가 없거나 복수일 수 있는 추출 계약
- 장소 단서별 1-based 입력 이미지 순번과 실제 관찰 텍스트 근거
- 같은 장소가 여러 이미지에 등장할 때 근거를 합친 단일 장소 단서
- 표지 제목, 장소 개수 문구, 지역명, 일반 업종명만으로 만든 잘못된 장소 제외
- 이미지 장소 출력 한도를 1,600 token으로 확대
- 이미지 근거를 기존 OpenAI 카카오 후보 선택 입력에 전달
- 실제 실패 이미지 7개 URL을 사용한 요청 구조 및 응답 파싱 회귀 테스트

## 제외 범위

- 좌측 하단, 가장 큰 글씨 등 특정 위치·크기 규칙
- 이미지당 최대 한 장소 가정
- 별도 OCR provider
- 영상 frame 추출
- 고성능 모델 자동 fallback
- 공개 API 또는 DB 스키마 변경

## 이미지 추출 계약

각 이미지는 입력 순서만 유지하며 내부 레이아웃은 가정하지 않는다. 모델은 이미지 전체를 확인하고
게시물이 방문, 소개 또는 추천하는 실제 영업 장소를 0개 이상 반환할 수 있다.

이미지 근거가 있는 장소에는 다음 정보를 포함한다.

- `imageIndex`: Responses API 입력의 첫 이미지를 1로 하는 순번
- `evidenceText`: 상호명 또는 주소를 판단하는 데 실제로 사용한 이미지 문구

텍스트 위치, 글자 크기, 번호 표기나 카드뉴스 형식은 근거 계약에 포함하지 않는다. 이미지가 없거나
본문·장소 태그만으로 얻은 단서는 근거 목록을 비워 둔다.

## 성공 기준

- 이미지 요청이 한 번에 최대 20장을 유지하면서 모든 이미지에 `detail: high`를 명시한다.
- 위치·크기·번호·카드 형식이나 이미지당 장소 개수를 가정하지 않는다.
- 한 이미지에서 0개 이상 복수 장소를 표현할 수 있다.
- 이미지 장소 단서가 이미지 순번과 관찰 텍스트를 포함한다.
- 이미지 근거가 카카오 후보 선택 입력에 포함된다.
- 텍스트 우선, OpenAI provider 오류 재시도와 기존 카카오 검증 정책을 유지한다.
- `./gradlew detekt`, 관련 테스트, `./gradlew check`가 성공한다.

## 검증

```shell
./gradlew detekt
./gradlew :nook-api-application:test
./gradlew :nook-api-infrastructure:test
./gradlew check
```

운영 검증에서는 NOOK-85에 기록한 이미지 7장을 포함한 게시물을 다시 처리해 이미지 단서와 카카오
장소 확정 결과를 확인한다.
