# NOOK-279 장소 파싱 실패 시 게시물 제목 기본값 보장

## 목적

장소 파싱이 실패하면 최종 제목 확정 단계에 도달하지 못해 게시물 제목이 `null`로 남는 문제를
해결한다. 장소 파싱 상태와 실패 원인은 유지하면서 서버가 게시물 제목을 항상 저장하도록 한다.

## 범위

- 장소가 하나도 확정되지 않은 경우에도 본문, 해시태그, 위치 태그와 첫 이미지 OCR로 제목을 확정한다.
- 제목 선택 provider가 실패하거나 근거 있는 제목이 없으면 `방문해보기 좋은 곳`을 결정론적 기본값으로 사용한다.
- 제목과 장소 파싱 실패 상태를 하나의 짧은 DB 트랜잭션에서 저장한다.
- 운영자가 수정한 제목은 자동 실패 처리로 덮어쓰지 않는다.
- 장소 파싱 성공 및 실패 경로의 회귀 테스트를 추가한다.

## 제외 범위

- `nook-client` 변경
- `nook-admin-web` 변경
- 공개 API 및 DB 스키마 변경
- 기존 게시물 일괄 보정

## 성공 기준

- 장소 파싱 실패 게시물의 제목이 `null`로 남지 않는다.
- 근거 있는 본문·OCR 제목을 기본 제목보다 우선한다.
- 장소 파싱 상태와 실패 원인은 기존 계약을 유지한다.
- 운영자가 수정한 제목은 보호된다.
- `./gradlew check`가 성공한다.

## 검증

- `./gradlew detekt`
- `./gradlew test`
- `./gradlew check`

## 검증 결과

- 장소 파싱 실패 전 근거 있는 제목을 선택하는 application 테스트 성공
- 제목 선택 결과가 없거나 provider가 실패할 때 기본 제목을 저장하는 테스트 성공
- 장소 파싱 실패 시 운영자가 수정한 제목을 보호하는 infrastructure 테스트 성공
- `./gradlew detekt` 성공
- `./gradlew check` 성공
