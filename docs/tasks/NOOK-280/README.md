# NOOK-280 다중 장소 카드 파싱 회귀 수정

## 목적

Instagram 매거진형 게시물의 번호 카드가 일부 누락되거나 반복 워터마크 아래 하나의 장소로 합쳐지고,
짧은 한글 상호명이 잘못 전사되는 문제를 줄인다.

## 원인

- 이미지 OCR에는 실제 상호명이 있었지만 장소 단서 추출에 `gpt-5-nano`를 사용해 설명문을 상호명으로
  선택하거나 서로 다른 카드들을 반복 워터마크 기준으로 병합했다.
- 본문에 `위치는 플로어 망원 입니다`라고 명시된 게시물도 텍스트 장소 단서가 비어 이미지 fallback에
  의존했다.
- `3 초라멘 | 화양동`의 카드 순번이 상호명에 포함됐다.
- `호뎅`을 `호덱`으로 전사해 올바른 지도 검색어를 만들지 못했다.
- `포비`는 상호명을 정확히 추출했지만 지도 provider가 화양동 업장을 후보로 반환하지 않았다.

## 범위

- 장소 단서 추출 전용 모델을 `gpt-5-mini`로 분리
- `PICK N` 문구를 이미지 기반 예상 장소 수로 사용
- `N 상호명 | 지역` 전사에서 순번을 제거하고 독립 장소 단서 복구
- 여러 번호 카드에 반복되는 매거진명·계정명·워터마크 제거
- 본문 명시 상호명, 설명문 금지, 카드 독립성 규칙을 OpenAI 지침에 보강
- 지역명 순서만 바꾼 중복 검색어를 제거하고 상위 행정구·인근역 검색어 확보
- Corepin 전사 오독이 비어 있지 않은 결과로 반환될 때 fallback이 실행되지 않는 한계 기록
- 385~388 실패 유형의 단위 회귀 테스트

## 제외 범위

- 공개 API 및 DB 스키마 변경
- 지도 provider에 등록되지 않은 장소의 임의 생성
- Instagram 태그 계정을 새로운 장소 provider로 사용하는 기능
- live 데이터 일괄 재파싱

## 성공 기준

- `PICK 7`이 주소 없는 카드에서도 예상 장소 수 7로 진단된다.
- 번호 카드의 상호명이 각각 복구되고 `Knewnew`, 카드 순번은 장소명에서 제외된다.
- 장소 단서 추출 요청이 `gpt-5-mini`를 사용한다.
- 포비처럼 올바른 provider 후보가 없는 장소는 잘못 연결하지 않고 미해결로 남긴다.
- 관련 단위 테스트와 `./gradlew check`가 통과한다.

## 검증

## 배포 및 롤백

스키마와 API 계약 변경은 없다. 애플리케이션 배포로 적용하며 문제가 있으면 이전 이미지로 롤백한다.
환경 설정이 없으면 장소 단서 모델은 `gpt-5-mini`를 기본 사용한다.
