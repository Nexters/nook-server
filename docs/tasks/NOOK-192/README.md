# NOOK-192 아카이브 공유 링크 및 공개 조회 API

## 목적

아카이브(서버 도메인의 그룹)를 읽기 전용 공유 링크로 공개하고, 로그인 사용자는 공유 아카이브를
복사하지 않고 자신의 아카이브 목록에 추가해 원본과 완전 동기화된 상태로 조회한다.

## 범위

- 그룹별 활성 공유 링크의 멱등 발급과 폐기
- 선택적 만료 시각을 포함한 공유 링크 상태 저장
- 비로그인 사용자의 공유 그룹 메타, 게시물, 장소, 게시물 상세와 장소 상세 조회
- 로그인 사용자의 공유 그룹 구독 추가와 제거
- 기존 그룹 목록에 소유 그룹과 활성 공유 그룹을 함께 반환
- 인증된 기존 그룹 게시물·장소 조회에서 소유자와 활성 구독자 허용
- 공유자의 닉네임과 프로필 이미지, 소유 유형 응답
- 공유 범위 밖 리소스와 모든 변경 동작 차단
- 공유 링크 상태별 오류 코드 분리

## 정책

- 공유 데이터는 복제하지 않고 원본 그룹과 사용자 저장 데이터를 조회한다.
- 공유받은 사용자는 그룹명, 색상, 게시물, 장소와 메모를 수정할 수 없다.
- 활성 링크 발급을 반복하면 기존 토큰을 반환한다.
- 폐기 후 다시 공유하면 새 토큰을 발급한다.
- 기본 공유 기한은 무제한이며 `expires_at`은 `NULL`이다.
- 폐기·만료·원본 그룹 삭제 시 기존 구독도 접근할 수 없다.
- 공유 장소 상세의 저장 게시물은 해당 공유 그룹에 포함된 게시물로 제한한다.
- 공유 게시물 상세의 본문과 메모는 공유자 기준으로 반환한다.
- 공유 게시물 상세의 그룹 정보는 선택적으로 인증된 현재 사용자가 동일 원본 게시물을 저장한
  자신의 그룹만 반환하며, 비로그인 사용자는 빈 목록을 반환한다.

## API 호환성

- 기존 endpoint, method와 필드는 유지한다.
- `GET /api/v1/groups` 응답에 `accessType`, `owner`, `shareToken` 선택 필드를 추가한다.
- 기존 클라이언트는 추가 필드를 무시할 수 있다.
- 공개 조회는 인증 없이 접근할 수 있고, 게시물 상세는 현재 사용자의 그룹 정보를 위해 인증을
  선택적으로 사용한다. 변경 API는 계속 인증을 요구한다.

## 오류 계약

- `SHARE_LINK_NOT_FOUND` (404): 존재하지 않거나 잘못된 토큰
- `SHARE_LINK_REVOKED` (410): 소유자가 폐기한 링크
- `SHARE_LINK_EXPIRED` (410): 만료된 링크
- `SHARED_GROUP_UNAVAILABLE` (410): 원본 그룹이 삭제되어 접근할 수 없음
- `SHARED_RESOURCE_NOT_FOUND` (404): 공유 그룹 범위에 없는 상세 리소스

## 제외 범위

- 클라이언트 저장소와 UI 구현
- 공유 그룹의 개인별 별칭·색상
- 공동 편집과 역할 기반 권한
- 공유 데이터 스냅샷 또는 복사
- bbox 지도 핀 공개 조회

## 성공 기준

- 활성 공유 링크가 멱등적으로 발급되고 폐기 즉시 접근이 차단된다.
- 로그인 여부와 관계없이 유효한 링크로 공유 범위의 모든 읽기 데이터를 조회할 수 있다.
- 로그인 사용자는 공유 그룹을 멱등적으로 구독하고 기존 그룹 목록에서 확인할 수 있다.
- 공유 구독자는 기존 그룹 조회 API를 사용할 수 있지만 변경 API는 사용할 수 없다.
- 공유 범위 밖 사용자 데이터가 응답에 포함되지 않는다.
- `./gradlew check`가 통과한다.
