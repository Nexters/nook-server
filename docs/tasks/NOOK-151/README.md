# NOOK-151 이미지 전사 부분 누락 허용 및 장소·제목 recall 개선

## 목적

OpenAI가 일부 이미지 전사를 생략하거나 1차 장소 단서 추론이 일부 이미지를 사용하지 않더라도 확보한 결과를
버리지 않는다. 본문에 명시된 기대 장소 수보다 결과가 부족할 때만 미사용 이미지에 대한 제한적인 보완 절차를
실행한다. 본문의 짧고 명시적인 모음 제목은 모델이 일반 제목을 반환해도 원문 표현을 유지한다.

## 범위

- 이미지 전사 응답의 누락 index를 빈 전사로 보완
- 같은 index의 중복 전사는 텍스트를 합치고, 요청하지 않은 index는 제외
- 전사 응답의 누락·중복·범위 밖 index를 warning 로그로 기록
- 본문의 기대 장소 수보다 1차 장소 단서가 부족할 때 evidence에 사용되지 않은 이미지만 보완 추론
- 미사용 이미지 중 전사 문자열이 1개 이하인 이미지만 최대 5장까지 조건부 재전사
- 보완 전사와 추론 실패를 1차 결과와 격리
- 기존 단서와 보완 단서가 같은 실제 검색 장소로 해석되면 provider 장소 ID로 중복 제거
- 지역명이 없는 본문도 첫 번째 짧은 문장이 업종과 장소 수를 명시하면 원문을 제목으로 사용

## 제외 범위

- 특정 게시물 ID, 이미지 순번 또는 상호명에 대한 예외 처리
- Naver OCR 도입
- 장소 검색 provider 교체
- 검색 후보가 없거나 모호한 장소의 강제 저장
- 기존 게시물 자동 일괄 재처리 API

## 성공 기준

- 일부 이미지 index가 빠지거나 중복된 전사 응답도 전체 작업이 실패하지 않는다.
- 요청한 모든 이미지 index가 순서대로 저장되고, 누락된 전사는 빈 배열을 갖는다.
- 기대 장소 수가 충족되면 추가 OpenAI 호출을 하지 않는다.
- 기대 장소 수가 부족하면 1차 단서에서 사용하지 않은 이미지만 보완 추론한다.
- 전사가 불충분한 미사용 이미지만 제한적으로 다시 전사한다.
- 보완 절차가 실패해도 1차에 확보한 장소는 완료 처리한다.
- `| 느좋카페 10선`처럼 장식 문자가 붙은 짧은 본문 제목은 `느좋카페 10선`으로 저장한다.
- `./gradlew check`가 통과한다.
