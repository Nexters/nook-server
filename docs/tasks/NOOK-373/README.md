# NOOK-373 어드민 장소 검색·목록 쿼리 성능 개선

## 목적

관리자 장소 검색과 목록 조회가 모든 장소를 애플리케이션 메모리에 적재하고 페이지 항목마다
추가 집계 쿼리를 실행하는 구조를 제거한다.

## 범위

- 검색, 정렬, offset/limit 처리를 MySQL 쿼리로 이동한다.
- 연결 게시물 수와 영향 사용자 수를 현재 페이지의 장소 ID로 일괄 집계한다.
- 기존 관리자 API의 검색 대상, 정렬, 응답 필드를 유지한다.
- 목록 전체 건수는 별도 count 쿼리로 계산한다.

## 제외 범위

- 관리자 웹 UI 변경
- 일반 사용자 장소 검색 API 변경
- 검색 방식을 전문 검색 엔진으로 교체

## 성공 기준과 검증

- 검색과 목록 조회가 `PlaceJpaRepository.findAll()`을 호출하지 않는다.
- 페이지 항목 수에 비례하는 집계 쿼리가 발생하지 않는다.
- 임의 offset과 limit이 DB에서 적용된다.
- 기존 API 계약 테스트와 `./gradlew check`가 성공한다.
