# NOOK-206 어드민 게시글 관리와 장소 관리 분리

## 목적

어드민 메뉴를 게시글 관리와 장소 관리로 분리하고, 공용 장소 원본의 영향 범위를 확인한 뒤
장소명과 주소를 감사 가능하게 수정한다.

## 범위

- 게시글 관리와 장소 관리 메뉴 분리
- 장소 목록 검색, 상세, 연결 게시글 조회
- 연결 게시글 수와 장소를 사용하는 저장 사용자 수 표시
- 장소명과 주소 수정, 수정 사유 필수
- 운영자와 변경 전후 값을 범용 감사 로그에 기록

## 제외 범위

- 장소 삭제와 병합
- provider 및 외부 장소 ID 변경
- 게시글 또는 사용자별 장소 연결 관계 변경

## 정책

사용자 저장 건은 장소 ID 연결 관계를 보존하지만 장소명과 주소는 공용 `places` 원본을 조회한다.
따라서 장소 정보 수정은 기존 사용자 화면에도 적용된다. 상세 및 수정 화면에서 영향 게시글 수와
저장 사용자 수를 먼저 표시하고, 수정 사유가 없는 변경은 허용하지 않는다.

## 검증

- `./gradlew check`
- `nook-admin-web`에서 `pnpm build`
