# NOOK-189 사용자 저장 게시물별 장소 연결 분리

## 목적

동일 Instagram URL의 파싱 원본은 재사용하되, 사용자가 저장한 게시물의 장소 추가·삭제가 다른 사용자에게
영향을 주지 않도록 장소 연결의 소유 경계를 사용자 저장 게시물로 분리합니다.

## 범위

- 공용 `posts`와 `post_places`는 Instagram 콘텐츠 및 최초 장소 파싱 결과 캐시로 유지합니다.
- 사용자별 장소 연결 테이블 `user_saved_post_places`를 추가하고 기존 데이터를 backfill합니다.
- 파싱 완료 원본 재사용과 최초 비동기 파싱 완료 시 사용자 게시물별 장소 연결을 생성합니다.
- 게시물·그룹·지도·장소 조회를 사용자별 장소 연결 기준으로 변경합니다.
- 수동 장소 추가와 삭제를 요청한 사용자 게시물에만 반영합니다.
- MySQL 8.4 DDL과 사용자 간 격리 회귀 테스트를 추가합니다.

## 제외 범위

- Instagram 원본 콘텐츠, 미디어, 해시태그의 사용자별 물리 복제
- 공용 장소 데이터 삭제 또는 사용자별 장소 복제
- 동일 사용자의 동일 Instagram URL 중복 저장
- 장소 후보 사용자 승인 UI
- 기존 공개 API 필드 변경

## 성공 기준

- 동일 URL을 저장한 두 사용자가 서로 독립적인 장소 연결을 가집니다.
- 한 사용자의 장소 추가·삭제가 다른 사용자의 게시물과 지도에 영향을 주지 않습니다.
- 기존 파싱 결과는 provider와 LLM을 재호출하지 않고 사용자 게시물에 복사됩니다.
- 기존 데이터가 마이그레이션 후 보존됩니다.
- 신규 삭제 API와 기존 API의 소유권 검증이 동작합니다.
- `./gradlew check`가 통과합니다.
