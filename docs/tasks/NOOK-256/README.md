# NOOK-256 Instagram 위치 태그를 지역 힌트로 제한

## 목적

Instagram 위치 태그가 구·도시·역·공원처럼 게시물 전체의 지역을 나타낼 때 이를 실제 영업 장소로
저장하지 않도록 위치 태그의 신뢰 범위를 제한한다.

## 원인

live에서 원문이 `#엘씨오 / 서울 광진구 능동로7길 24`를 안내했지만 위치 태그
`건대입구역 7호선`이 장소명으로 채택됐다. application은 본문과 해시태그뿐 아니라 위치 태그도 장소
단서의 근거로 인정했기 때문에 모델이 위치 태그를 장소로 반환하면 역 검색 결과와 주소가 그대로 저장됐다.

## 범위

- 위치 태그를 장소명과 주소의 직접 근거에서 제외
- 위치 태그는 장소 추출 모델의 지역 및 검색어 보조 힌트로만 전달
- 본문·해시태그·이미지에 상호 근거가 없으면 위치 태그만으로 장소를 생성하지 않음
- 본문 주소와 위치 태그가 충돌하면 본문 주소 우선
- 위치 태그가 지역 또는 역인 게시물 회귀 테스트 추가

## 제외 범위

- 기존 live 데이터 정정
- Instagram provider 변경
- 공개 API, 데이터베이스 스키마 및 클라이언트 변경

## 성공 기준

- `건대입구역 7호선 + #엘씨오 + 능동로7길 24`에서 역이 장소로 저장되지 않는다.
- `광진구 카페 7곳`에서 광진구가 장소로 생성되지 않는다.
- 위치 태그는 실제 상호 추출 후 지역 검색어를 구성하는 데만 활용할 수 있다.
- `./gradlew check`가 성공한다.

## 검증

- `./gradlew :nook-api-infrastructure:test --tests '*OpenAiContentInferenceAdapterTest'`

## 배포 및 롤백

스키마와 공개 API 변경은 없다. 애플리케이션만 배포하며 문제가 생기면 이전 버전으로 롤백한다.
기존 live 오매칭 데이터는 별도 운영 작업으로 정정한다.
