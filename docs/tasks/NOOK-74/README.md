# NOOK-74 장소 파싱 부분 성공 결과 저장

## 목적

Instagram 게시물에서 복수 장소를 추출한 뒤 일부 장소만 정확히 매칭되는 경우, 정상 매칭된 장소까지
모두 버려지는 문제를 개선한다.

현재는 모든 장소 단서가 하나의 후보로 매칭되어야 저장이 완료된다. 하나라도 후보가 없거나 복수
후보로 판정되면 전체 작업이 재시도되고 최종 실패하여 앞서 매칭된 장소도 저장되지 않는다.

## 범위

- 개별 장소의 후보가 없거나 복수로 매칭되면 해당 장소만 제외
- 하나 이상의 장소가 정상 매칭되면 성공한 장소만 저장하고 파싱 작업을 `COMPLETED` 처리
- 제외된 장소와 실패 사유를 로그로 기록
- 모든 장소가 매칭되지 않으면 기존 재시도 및 최종 `FAILED` 정책 유지
- 장소 검색 provider 오류와 타임아웃은 기존처럼 전체 작업 재시도
- 부분 성공, 전체 매칭 실패, provider 장애 회귀 테스트 추가

## 제외 범위

- 상호명 부분 일치 또는 지점명 제거 등 장소 이름 매칭 기준 완화
- 장소 파싱 상태와 API 응답 계약 변경
- DB 스키마 변경
- 사용자의 장소 후보 직접 선택

## 성공 기준

- 5개 장소 단서 중 2개만 정상 매칭되면 2개 장소만 저장된다.
- 개별 매칭 실패 때문에 정상 매칭 결과가 유실되지 않는다.
- 모든 장소가 매칭되지 않거나 provider 장애가 발생하면 기존 재시도 정책을 유지한다.
- `./gradlew check`가 성공한다.

## 검증

```shell
./gradlew :nook-api-application:test \
  --tests org.every.nook.api.application.place.ProcessPlaceParsingJobUseCaseTest
./gradlew check
```
