# NOOK-270 장소 주소 공백 정규화 및 명시 주소 기반 후보 복구

## 목적

도로명 내부 공백과 지번·도로명 표기 차이로 올바른 장소 후보가 제거되거나 장소 파싱이 실패하는 문제를 개선한다.

## 범위

- 숫자로 시작하는 도로명과 번호형 도로명의 내부 공백을 정규화한다.
- `한강대로 11길 21`과 `한강대로11길 21`을 같은 주소로 판정한다.
- 명시 주소 검색으로 찾은 상호명 접두 일치 후보를 행정구역 및 층·호 충돌이 없는 경우에만 복구한다.
- 본문 앞쪽의 명시 상호명과 뒤쪽 별도 주소 문단을 연결하도록 장소 추론 프롬프트를 보강한다.
- 로파서울과 미례국밥 재현 사례 및 충돌 방지 회귀 테스트를 추가한다.

## 제외 범위

- 지도 provider 변경
- DB 스키마 또는 API 계약 변경
- 기존 실패 게시물의 자동 재처리
- live 배포
